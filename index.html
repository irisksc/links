탕전 물양 계산기

해나무한의원
투입할 물의 양 =
  포장 필요량 (1포당 용량 × 총 갯수)
  + 약재흡수량 (약재 무게 × 배수)
  + 증발량

1. 약재 정보

제외 대상: 석고, 분말류(모려·용골·사인 등)

2. 계절

계산 무게가 500g 이하이면 계절 배수 대신 500g 이하 기준(× 0.5 / × 0.8)이 자동 적용됩니다.

↳ 계산 무게 500g 이하 — 계절 배수 대신 소량 약재 기준이 적용됩니다.

3. 포장 정보

최종 투입 물양
0cc

계산 전 확인

  1. 일반약인지 녹용약인지 확인한다.
  2. 제외 품목을 뺀 실제 계산 무게가 500g 이하인지, 1kg 이하인지 확인한다.
  3. 계절 조정 배수와 소량 약재 기준이 겹치면 소량 약재 기준을 우선한다.
  4. 최종 물양이 포장에 필요한 약액보다 충분한지 확인한다.
  5. 애매하거나 평소 계산량과 차이가 크면 물을 넣기 전에 선임자에게 확인한다.
정리된 계산 규칙 기반 · 판단이 애매한 경우 선임자에게 확인해 주세요
